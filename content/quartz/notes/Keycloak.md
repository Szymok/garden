## 👽 Brudnopis
KeyCloak is an open-source 3rd party identity management software used across the whole Ataccama platform The KeyCloak URL is usually: cataccama-one-URL>/auth TO manage users and roles, a user needs to log in to KeyCloak Admin Console as the admin user into the Ataccamaone realm. A Realm refers to an object managing a set of users with their credentials, roles, and groups. A user refers to the entity that logs into the Ataccama application. A Role refers to an entity that determines user privileges once they are logged in; more than one role can be assigned to a user,
