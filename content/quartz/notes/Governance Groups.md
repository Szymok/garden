## 👽 Brudnopis
Groups are a hierarchical representation of data teams. These teams can be teams of users, departments, branches — any group Of users Each user in a group can have a specific role that represents their responsibilities within the group. One user can be a member of several groups. A user Can have different roles within different groups, To manage groups in ONE, you need the ONE Administrator governance role. you can see the list of existing groups by navigating to Global settings user Management Groups.
