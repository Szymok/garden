## 👽 Brudnopis
By using the Sources section under the [[notes/Data Catalog|Data Catalog]] section, a user can: • • Create and manage Data Sources. View information on the created sources. Run Data Discovery and Profiling for each selected source. Run the Documentation Flow for each selected source.

Multiple connections can be specified for one data source. Connections can be of different types (Amazon S3, Oracle, etc.) Set credentials as default for profiling or DQ evaluation. For every connection multiple credentials can be defined. Validity of the connection can be tested using the Test Connection button. Delete a data source instantly by clicking on Instant delete.
