## 👽 Brudnopis
The information you can see on the Data Catalog tab depends on your global role and access level, and whether access was shared with you. Reports: allows to manage in ONE all Bl reports on catalog items that are build in Bl tool. Anomaly Overview: a list of all catalog items with anomalies. Data Export Projects: all data export projects created in ONE. Master Data: a list of all catalog items contained within MDM data sources. Reference Data: a list of all catalog items contained within RDM data sources. Not Monitored: a list of all catalog items that are not currently included in any monitoring projects.
