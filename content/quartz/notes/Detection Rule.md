## 👽 Brudnopis
- Selecting Term Detection as the rule type as well as the type of detection is done while rule creation before saving. 
- Rule logic configuration is located under the Implementation tab. The condition should be defined so that if satisfied, the term is detected. 
- There are two options for defining the condition: 
	- Condition Builder — offers predefined logical operations like 'is empty' or 'is from a reference data'. 
	- Advanced Expression — offers writing complex condition.
