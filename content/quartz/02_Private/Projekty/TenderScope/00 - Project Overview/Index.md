# TenderScope - Project Overview

## Vision

Build a European AI-powered public procurement intelligence platform starting with the Polish market, designed from day one for international expansion.

## Core Value Proposition

- Never miss a tender - Smart alerts matching business profile
- AI-powered insights - Predictive analytics for success probability
- Multi-country coverage - Poland → Czechia → EU
- Developer-friendly - Open API for ecosystem

## Target Market

- Primary: Small and medium Polish companies participating in public tenders
- Secondary: EU companies looking for cross-border opportunities
- Tertiary: Journalists, analysts, NGOs (transparency tools)

## Unique Differentiators vs Mimira

1. Freemium model (not success fee)
2. International from day 1 (multi-tenant, i18n)
3. Open API marketplace (ecosystem approach)
4. Transparency focus (NGO/journalist segment)
5. Advanced ML features (budget prediction, anomaly detection)

## Success Metrics

- MVP (3 months): 50-100 users, 500+ tenders indexed
- Phase 2 (6 months): 500 users, 10 paying customers
- Phase 3 (12 months): Czech market launch, 2000+ users

## Project Timeline

- Q1 2026: Polish MVP + TED foundation
- Q2 2026: AI features + Premium launch
- Q3 2026: Czechia expansion
- Q4 2026: Slovakia + Estonia
- 2027: Germany/France (major markets)
